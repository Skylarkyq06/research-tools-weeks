\section{实验原理}

\subsection{Git}
Git 是分布式版本控制系统。工作区保存正在编辑的文件，暂存区保存准备提交的变化，
commit 把暂存内容记录到本地仓库，push 上传到 GitHub，pull 拉取远程更新。

\subsection{Codex 与 CC Switch}
Codex 是 AI 辅助编程工具，能在授权范围内读取项目、修改文件并运行本地工具。
CC Switch 用于管理 Codex 的供应商配置，可将请求转发到 DeepSeek 等第三方 API。

\subsection{LaTeX 图片排版}
矢量图保存曲线、文字和几何对象，缩放时保持清晰。科研图表优先导出为 PDF。
LaTeX 通过 graphicx 宏包插入图片，caption 负责图题，label 与 ref 建立引用。

\section{实验过程}

\subsection{Git 与 GitHub}

\subsubsection{安装与配置}
使用 \texttt{git --version} 确认安装，使用 \texttt{git config --global} 配置姓名和邮箱。

\subsubsection{仓库创建与提交}
\begin{lstlisting}[language=bash]
git clone https://github.com/Skylarkyq06/research-tools-weeks.git
cd research-tools-weeks
mkdir -p code result report figures
git add README.md code/ result/ report/ figures/
git commit -m "add first experiment program"
git push -u origin main
\end{lstlisting}

\subsubsection{同步远程更新}
在 GitHub 网页修改 README 后，本地执行 \texttt{git pull} 同步。

\subsection{Codex 与 CC Switch}

通过 npm 安装 Codex CLI，使用 CC Switch 将供应商切换为 DeepSeek。

\subsubsection{Codex 辅助编程}
让 Codex 阅读项目并完成词频统计任务，生成 \texttt{code/text\_stats.py}。
运行结果如下：

\begin{lstlisting}[language=bash]
python code/text_stats.py sample.txt
\end{lstlisting}

通过本次实验，我掌握了 Git 的基本提交流程：pull → 修改 → status/diff → add → commit → push。
